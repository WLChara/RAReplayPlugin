# RAReplayPlugin

《红色警戒 2：尤里的复仇》对局录制与回放插件。

插件通过 Syringe 加载到游戏中：对局时录下玩家命令，回放时在游戏内逐帧重演整局，并在画面上叠加观看界面。录像文件扩展名为 `.yrrep`。本仓库包含插件源码、离线测试、调试工具，以及供启动器接入用的 C# 类库。不包含游戏文件、完整客户端或已构建的二进制文件。

## 功能

**录制**

- 支持遭遇战与联机对局。
- 录下玩家命令，以及会影响模拟结果的本地输入副作用（例如移动指令的提示动画）；单机对局还会记录中途调整的游戏速度。
- 录像边写边存，异常退出时留下的未完成录像也能播放到最后一个完整帧。
- 录像按块压缩，每块带校验，完成的录像另有整体哈希。

**回放**

- 在游戏内按原始帧重演；联机录像逐帧核对同步校验值，发现不一致立即停止。
- 回放期间屏蔽观看者对单位的操作，不影响录像本身。

**观看界面**

- 暂停、继续，重新播放，退出回放。遭遇战与联机录像的重新播放在游戏内完成，不需要重启游戏。
- 七档观看速度（遭遇战录像）。
- 进度条显示游戏时间，点击或拖动即可跳转，跳转中可以取消：
  - 跳到之后的时刻：游戏快进过去，快进中不绘制战场，画面中央显示“快进中”；
  - 回到更早的时刻（遭遇战与联机录像）：游戏重新载入场景，再快进到那里，到达后保持跳转前的播放或暂停状态。
- 侧边面板：总览、生产（含停产记录）、部队、编队、经济（资金曲线，可展开为大窗口）。
- 雷达事件提示：超级武器释放、建筑被渗透，并在地图上标出超级武器落点。
- 战局缩放：1/3× 到 4×，可用 Ctrl + 滚轮或界面按钮调整。
- 半透明黑幕，只改变绘制，不改变地图揭示与模拟。
- 按 F10 隐藏或显示界面。

## 环境要求

- 只支持下面这个 `gamemd.exe`：

  ```text
  SHA-256 7cd005d263fde203d9c84548200a057a8df61d724da3c6bd1e521eeb61cd0747
  ImageBase 0x400000
  ```

- 观看界面通过 Direct3D 9 或 OpenGL 绘制；使用 GDI 软件渲染时不显示界面。
- 录制与回放都由启动器发起：启动器负责生成录制或播放请求、校验地图、恢复开局配置；插件负责录制、重演和观看界面。`integrations/csharp` 中的 `RAReplay.Client` 类库实现了启动器一侧的文件格式与请求协议，可供基于 .NET Framework 4.8 的启动器引用。

## 构建与测试

需要 Windows、Visual Studio 2022（C++ 桌面开发与 .NET Framework 4.8 开发工具）、Windows SDK、CMake 与 PowerShell。插件按 Win32/x86 构建。

```powershell
.\scripts\build.ps1 -Configuration Release
```

该脚本依次运行模块边界检查、编译与全部离线测试，插件产物位于 `build/v2/Release/RAReplayPlugin.dll`。

C++ 与 C# 两侧的文件格式贯通测试：

```powershell
.\scripts\test-protocol-bridge.ps1
```

C# 类库的导入导出功能依赖 DotNetZip 1.9.1.8 的 `Ionic.Zip.dll`。项目默认从游戏安装目录的 `Resources\Binaries` 引用它；不在默认位置时，构建类库、测试或示例需要指定路径：

```powershell
dotnet build integrations\csharp\RAReplay.Client.Tests\ReplayClient.Tests.csproj -p:IonicZipPath=<Ionic.Zip.dll 的路径>
```

Syringe 握手测试。它只把指定的游戏可执行文件复制到临时目录做身份校验，不会启动游戏：

```powershell
.\scripts\test-plugin-handshake.ps1 -GameExe 'D:\Games\Yuri\gamemd.exe'
```

## 目录

| 目录 | 内容 |
| --- | --- |
| `src` | 插件源码，按职责分模块：录像数据与会话、文件容器与协议、游戏适配、Hook、统计、观看界面与绘制、战局缩放等 |
| `tests` | 离线测试与样例文件 |
| `tools` | 观看界面的离线预览与 Direct3D 9 冒烟测试工具 |
| `integrations/csharp` | 启动器侧的 C# 类库、测试与示例 |
| `third_party` | 第三方依赖 |

## 已知限制

- 回到更早的时刻需要重新载入场景并从开局快进，长录像跳到后段要等待较长时间。战役录像暂不支持回到更早的时刻。
- 联机录像暂不支持调整观看速度。
- 录像格式会随版本升级。新插件可以播放旧录像，但旧插件与旧客户端无法打开新版本的录像，所以插件与启动器需要一起更新。
- 只在列出的游戏版本上验证过，不保证覆盖所有对局类型、对局长度与图形后端。
